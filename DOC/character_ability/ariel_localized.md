# 魔王爱丽儿（Ariel）· 饥荒本土化能力设计

> 本文件为爱丽儿的 DST 本土化能力设计（可实装向）。角色**源设定（原文提取）**见同目录 `ariel.md`；身世与性格背景见 `../charactors/ariel.md`。
>
> **设计方针**：**最强魔王·极端代价制衡**——保留接近源设定的高强度，以极端常驻代价（超高耗粮、不可逆生命上限衰减、谦虚脱力）作为唯一制衡杠杆，而非靠脆弱身板。与白织（Shiro）重叠的主题一律**同主题不同玩法**，不做换皮。

> 「我来了。魔王少女爱丽儿，华丽登场！……多杀一些，多死一些，化为这颗星球的养分吧～」

---

## 角色概览

* **定位**：重装近战狂战士 / 召唤统御型魔王（与白织的「敏捷型法系机动刺客」完全反向）
* **基础三维**：
  * **生命值 (Health)**：300（先天硬朗，但会被「灵魂磨损」不可逆蚕食）
  * **饥饿值 (Hunger)**：250（代谢 1.5 倍，长期缺粮压力）
  * **理智值 (Sanity)**：200
  * **暴食储能池 (Gluttony Pool)**：0–100 专属仪表（替代白织的 MP 徽章）
* **人物特征 (Perks)**：
  * *原初蜘蛛真祖，号令万蛛（含女王）*
  * *暴食之胃，吞噬万物化为霸体动力*
  * *神兽体质，徒手即凶器，常驻 25% 物理免伤*
  * *千杯不醉的顶级厨师与推拿宗师*
  * *代价：极重食量与「灵魂磨损」——强力技能会不可逆削减生命上限*

## 先天被动与种族特质

1. **真祖支配 (True Ancestor Domination)**：
   * 所有蜘蛛（黑蜘蛛、战士蜘蛛、洞穴蜘蛛、各类变种，乃至**蜘蛛女王**）默认视爱丽儿为最高主宰，完全友好、绝不主动攻击。
   * **主动号令**（无消耗）：右键野生蜘蛛纳入「蛛群」跟随作战或护卫，无需喂肉；同时统御上限 8 只普通蜘蛛，另可临时号令 1 只蜘蛛女王跟随 60 秒（较长冷却）。
   * 被号令的蜘蛛对爱丽儿无仇恨、无维持消耗；长时间离开范围或过夜自动脱离。
   * 常驻免疫蛛网地面减速，踩网不触发蛛巢警觉出兵。
   * 主动攻击某只蜘蛛或破坏其蛛巢，会短暂中断该目标的臣服（护巢反击），但不永久失去支配。
   * *与白织的区别：白织是「被动中立 + 免疫」；爱丽儿是「完全友好 + 主动指挥 + 可号令女王」。*

2. **神兽体质·近战霸权 (Divine Beast Physique)**：
   * 徒手基础伤害 34（普通角色约 10），命中附带击退；徒手 / 近战命中额外积累少量暴食储能（把「打」和「吃」联动）。
   * 先天移速 +10%（低于白织 +15%，因她是重装且有近战补偿）。
   * **魔王突进**：短距战斗冲刺（消耗 15 储能，短冷却），朝向瞬移约 6 单位、穿过并击退小型敌人。定位战斗位移，非旅行传送（与白织空间转移区分）。

3. **物理与元素抗性 (Resistances)**：
   * 常驻 **25% 物理伤害减免**。
   * 免疫：雷击伤害、毒素伤害（毒腺 / 蜘蛛毒 / 沼泽毒气）、湿身带来的额外理智流失与地面滑落负面（不完全防雨，但不受湿身减益）、风暴（沙尘暴 / 剧风）的视野与强制位移。
   * 暗影阵营抗性：受暗影 / 月亮来源伤害降低（对齐 `allegiance` 体系，倾向 shadow 阵营）。

4. **千杯不醉 (Unshakable Drunkard)**：
   * 与白织正相反：摄入酒精饮料 / 料理进入正面「微醺」增益（小幅 +攻击、+理智恢复），无暴走失控、无宿醉。

## 主动技能与核心机制

1. **暴食 (Gluttony)** —— 核心资源引擎：
   * 「吞食」是一个右键动作，可作用于地面掉落物、尸体残骸、材料、装备，乃至**飞来的敌方投射物**，转化为饥饿 + 暴食储能：
     * 吞食可食用物：转为等量饥饿 + 其饥饿值 ×0.5 储能。
     * 吞食非食用物（材料 / 装备 / 怪物残骸 / 投射物）：按物品价值折算 5–25 储能 + 少量饥饿（转化收益低于制作成本，杜绝无限刷）。
   * **储能自然衰减**：脱战每秒 −1.5，战斗中（近 8 秒内有攻防）暂停衰减——迫使她持续进食。
   * **霸食态阈值增益**：
     * ≥30：攻击 +15%，生命再生 +1/s。
     * ≥60：攻击 +30%，生命再生 +2/s，受击硬直减免 50%。
     * ≥90：攻击 +50%，生命再生 +4/s，**完全霸体**（免疫硬直 / 击退 / 冰冻位移），移速 +10%；但此档衰减翻倍（越强越费「油」）。
   * *与白织「恶食」的区别：白织只是把食物负面值归零；爱丽儿是主动吞噬 → 驱动霸体狂战的能量循环。*

2. **操偶蜘蛛召唤 (Puppet Spiders · 神织操偶四姊妹)**：
   * 材料：**操偶丝**（爱丽儿专属，蛛丝 + 怪物肉 / 噩梦燃料精炼）。每名召唤消耗 1 操偶丝 + 20 饥饿。
   * 四名具名操偶少女，战斗分工不同：
     * **阿艾尔（大剑）**：高伤慢速，命中小范围 AoE 击退。
     * **萨艾尔（长枪）**：中距突刺，可穿刺 / 打断。
     * **莉艾尔（双刀）**：高攻速多段连击。
     * **菲艾尔（盾）**：高生命坦克，嘲讽拉怪、格挡减伤、护卫本体与队友。
   * 生命有限（约 200），可被消灭，死亡后需重新召唤（短暂再召冷却）；同时最多 4 名，每名每秒消耗微量饥饿维持。
   * 指令：跟随作战 / 驻守巡逻（守营）/ 集火指定目标。
   * *与白织「白色小蜘蛛分体」的区别：白织分体是侦查揭图 + 破卵复活载体；爱丽儿操偶是分工明确的战斗随从，可搬运。*

3. **深渊魔法·地狱门 (Abyss Magic · Gate of Hell)** —— 终极处刑 AoE：
   * 指向地面施法，半径 5、施法距离 12，生成持续 5 秒的暗黑引力漩涡：范围内非友方生物移速 −60% 并被缓慢牵引向中心。
   * **灵魂处刑**：漩涡期间每 0.5 秒判定，当前生命 ≤20% 的普通敌人（非 Boss、非玩家）直接处决（撕裂灵魂秒杀）。
   * **深渊伤害**：对 Boss / 精英 / 免处决目标，持续造成 `abyss` 深渊伤害（合计约 500，5 秒分摊），绕普通护甲但遵守 `abyss` 深渊抗性与 Boss 无敌阶段，**非绝对真伤**（对齐白织死灭之邪眼的承伤规则）。
   * **代价**：消耗 60 暴食储能 + 立即 **−15 最大生命上限（灵魂磨损，仅温养料理可复）**；冷却 120 秒。
   * 不以玩家为目标，自动排除友方随从 / 操偶 / 蛛群；空放（无有效目标）不扣储能、不扣上限、不进冷却。

4. **谦虚 (Humility · 最终决战姿态)** —— 紧急底牌：
   * 激活：立即将当前最大生命上限的 25% 转为灵魂磨损（永久 −，仅温养恢复）+ 消耗 50 理智。
   * 决战姿态（15 秒）：全伤害 +100%、攻速 +50%、移速 +25%、额外 +40% 伤害减免、完全霸体、暴食储能停止衰减且徒手命中积累翻倍。
   * 脱力（结束后 20 秒）：移速 −40%、全伤害 −50%、无法奔跑 / 突进、三维自然恢复暂停、暴食增益失效。
   * 冷却：一个游戏日（或约 8 分钟）。真·底牌，滥用会持续削减她的生命上限。

## 专属制作与料理

1. **魔物烧烤**（怪物肉主料）：可安全大量食用，产出全队短时「战意」增益（+攻击 / +伤害减免）。
2. **香菇全餐**（蘑菇主料）：全队大额三维恢复 + 抗性增益。
3. **温养料理（高级）**：**唯一**能恢复「灵魂磨损」（最大生命上限惩罚）的手段；配方昂贵（高级食材 + 操偶丝 / 深渊材料），每份缓慢回复固定上限点数（触发 `buff_health_penalty_reduction`）。
4. **神级推拿**：右键其他玩家「按摩」，清除其可清除负面（发抖 / 低温后遗 / 宿醉 / 湿身减益等）+ 恢复少量理智与饥饿；有冷却，消耗爱丽儿少量储能。
5. **操丝椅 / 丝床**（建筑）：坐 / 躺时快速恢复生命与理智（不直接回饥饿，避免破坏生存循环），供全队使用；呼应结局「由操偶四姊妹用丝椅抬着走」。

## 进阶与技能树规划（骨架）

* **分支一·暴食之道**：储能上限 / 转化效率、霸食态阈值增益强化、可吞食种类扩展、突进强化。
* **分支二·蛛群统御**：操偶四姊妹强化与专属技、蜘蛛女王指挥时长 / 数量、建造专属蛛巢。
* **分支三·深渊魔道**：地狱门半径 / 伤害 / 处刑阈值提升、谦虚强化、**灵魂磨损代价减免**（降低每次 −上限量或提升温养恢复效率）。
* **魔王专属特质**（仿白织 Dominator，需前置解锁）：如「暴食·无尽」（储能不再自然衰减）、「支配·万蛛」（蛛群上限翻倍）、「深渊·真祖」（处刑阈值 / 深渊穿透提升）等，节点待细化。

## 缺点与限制（核心制衡杠杆）

1. **巨大食量负荷**：饥饿消耗 1.5 倍；暴食储能持续衰减，维持霸食态必须不断进食——长期缺粮压力。
2. **灵魂磨损**：地狱门 / 谦虚造成**不可逆最大生命上限衰减**，仅温养料理可缓慢恢复——强力技能越用身板越脆，形成「高级料理经济」依赖。
3. **冷场大王**：周期性 / 主动讲冷笑话，若附近有其他玩家且无互动响应，小范围（含自己）理智轻微下降。
4. **重装无机动**：相对白织缺乏疾影 / 空间传送等逃生手段，突进仅为短距战斗位移，定位硬碰硬近战，走位容错低。

## 实现备注（资源与系统对接）

* **动画资源**：爱丽儿暂缺专属人物动画；实装阶段所有缺失的人物 build/anim **暂以白织（shiro）默认 build 作为模板替代**，后续再替换为专属美术。
* **注册状态**：爱丽儿尚未实装——已有 `scripts/speech_ariel.lua` 与 `strings.lua` / `speech_extension.lua` 的 ARIEL 语音，但无 `scripts/prefabs/ariel.lua`，且未在 `main/characters.lua` 用 `RegisterCharacter` 注册。
* **深渊伤害**：地狱门走既有 `abyss` 特殊伤害类型（`components/abyssdamage`｜`abyssdefense`，基于 `planardamage` / `spdamageutil`），与白织的 `erosion` 分家。
* **暴食储能池**：作为独立自定义仪表（非 MP），走 `TUNING.CHARACTER_DETAILS_OVERRIDE` 自定义计量条注入（参照 `shiro_sanity = "magicpoint"` 的做法）。
* **灵魂磨损恢复**：温养料理触发已预留的 `buff_health_penalty_reduction`（台词已含 `ANNOUNCE_ATTACH_BUFF_HEALTH_PENALTY_REDUCTION`）。
* **千杯不醉**：复用醉酒 buff 框架但对爱丽儿改为正面效果（台词已含正面语气的 `ANNOUNCE_ATTACH_BUFF_DRUNKEN`）。
* **阵营**：倾向 shadow 阵营，套用现有 `allegiance` 抗性体系。
* **数值定位**：本文数值为设计基线；实装时按平衡实测调参，尤其「25% 物理免伤 + 300 生命 + 霸体 + 回血」的坦度须由「灵魂磨损 + 1.5 倍耗粮」实测制衡。
