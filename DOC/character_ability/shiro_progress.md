# 白织（Shiro）功能与资源进度

> 目标设计见 [shiro.md](shiro.md)。以下以代码实际状态为准；“已实现”不等于已完成全部游戏内验收。

## 已实现的功能

- 基础生命75、饥饿180、理智150、MP150；饥饿归零时独立流失理智。
- 恶食的负生命／负理智营养过滤、忽略食物新鲜度惩罚，以及腐烂食物的特殊营养结算。
- 蜘蛛亲和、蛛网警戒与减速保护。
- 6／9／12格异空间、空间Ⅲ重物收纳、短距和地图转移。
- 空间机动开关、无承托时的持续MP消耗、MP归零停用；不生成踏水地板特效。
- 韦驮天的渐进加速、停步衰减、随加速倍率变化的耗粮及组件移除清理。
- 静止、诅咒、死灭、催眠、引斥与怠惰法术的施法入口及基础效果。
- 分体制造、部署、数量限制、私人揭图、收回、归属保存及幽灵复活入口；分体死亡清理与碰撞修正。
- 大体型进化的两次生命上限增加、15%／30%减伤档位和HUD刷新。
- 阿剌克涅二重攻击、女王形态的附近无主蜘蛛招募。
- 忍耐的爆发伤害分摊、延迟伤害MP保命与任务清理。
- 神织丝袍的创建即神织化、防雨、保暖、绝缘、自修补与两格容器。
- 大镰刀的腐蚀伤害与持续腐蚀、角色命中反馈、反噬、工具用途和定时自修复。
- 醉酒暴走、踉跄、猫尾台词、醒酒睡眠、宿醉及火焰受击硬直处理。
- 新增法术轮盘图标、分体物品栏图标和装备标签识别。
