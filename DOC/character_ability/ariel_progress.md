# 爱丽儿（Ariel）功能与资源进度

> 本土化目标见 [ariel_localized.md](ariel_localized.md)；原设定见 [ariel.md](ariel.md)。以下区分功能实现与正式美术完成度。

## 已实现的功能

- 可选角色注册、默认皮肤、300／250／200基础三维、1.5倍耗粮、34徒手伤害及神兽体质。
- 蜘蛛亲和、无主蜘蛛号令、蜘蛛女王临时统御、数量／距离／夜间限制及解除清理。
- 独立暴食储能、食物与近战储能、非食物和敌方投射物吞噬，以及物品所有权／容器／活物保护。
- 三档霸食态、持续恢复、伤害提升、受击硬直缩短及高档霸体。
- 魔王突进、地狱门、最终决战与脱力、灵魂磨损及温养修复。
- 操偶四姊妹的不同战斗分工、召唤与维持代价、跟随、驻守巡逻、集火、收起及生命状态保存。
- 操偶丝、操丝椅、丝床、蛛巢制作，以及三种专属制作料理与团队增益。
- 推拿、微醺、冷笑话与表情回应判定。
- 三分支13节点技能树、13项技能轮盘入口、四个右键动作、储能HUD及存档同步。
- 中文界面、检查台词和本地化条目接入。

## 仍需完成的验收

- 图形前端的选人、头像、HUD、技能树和技能轮盘显示。
- 远端玩家的右键交互、施法输入与攻击速度同步。
- 真实地面／洞穴迁移中的操偶、磨损、姿态、冷却及临时蛛群清理。
- 长时间存档运行、多人战斗和平衡性验收。

以上是验收缺口，不代表相应代码尚未编写。不将原设定中未纳入本土化基线的能力自动加入待办。
